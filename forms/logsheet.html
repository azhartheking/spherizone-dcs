How to fill in this log

  1. Take a full round of readings from the DCS every 2 hours (write the actual clock time at the top of each column), plus one at the start and end of the shift.
  2. Write the value exactly as shown on the DCS, with the same number of decimals.
  3. Compare each reading with the Normal range. If it is outside, circle it in red and enter it in the deviation record on page 5 with the action taken.
  4. Grade-dependent values: the bracket shows the R-7 (RACO) value; H-BOPP and H-FIBER exceptions are noted. For anything else use the setpoint card (SZ-CL-05).
  5. GPR section (R-401): only when HS-302 is IN SERVICE. Otherwise write N/A once across the row.
  6. Status rows: write R = running, S = stopped, A = AUTO, M = MAN.
  7. Record every alarm, trip, operator intervention and lab result on pages 4–5.
